# Introducción a la Ingeniería de Software

La **Ingeniería de Software** es la disciplina que aplica principios de ingeniería al desarrollo de software: planificar, diseñar, construir, verificar y mantener aplicaciones de forma ordenada, reproducible y medible.

```
Requisitos → Diseño → Codificación → Pruebas → Mantenimiento
```

---

## ¿Por qué necesitamos Ingeniería de Software?

Escribir código que funcione es solo una parte del trabajo. Sin un proceso definido, los proyectos tienden a:

- Incumplir plazos y presupuestos.
- Entregar un producto que no satisface las necesidades del cliente.
- Acumular **deuda técnica**: código difícil de mantener y ampliar.
- Fallar al escalar cuando el equipo crece.

La Ingeniería de Software proporciona el marco para evitar estos problemas.

---

## El ciclo de vida del software

Todo software pasa por una serie de fases desde que se concibe hasta que se retira. A este conjunto de fases se le llama **ciclo de vida del software** (Software Development Life Cycle, SDLC).

Las fases fundamentales son:

| Fase | Descripción |
|------|-------------|
| **Planificación** | Definir alcance, recursos, riesgos y plazos |
| **Análisis de requisitos** | Recopilar y documentar qué debe hacer el sistema |
| **Diseño** | Definir la arquitectura y estructura del software |
| **Codificación** | Implementar el diseño en un lenguaje de programación |
| **Pruebas** | Verificar que el software cumple los requisitos |
| **Mantenimiento** | Corregir errores y añadir mejoras tras la entrega |

---

## Modelos y metodologías: la diferencia

Es importante distinguir dos conceptos que a menudo se confunden:

- Un **modelo de ciclo de vida** describe *qué fases* existen y en qué orden se ejecutan (p. ej., Cascada, Iterativo).
- Una **metodología** concreta *cómo* se ejecutan esas fases: roles, artefactos, técnicas y herramientas (p. ej., Métrica v3, Ágil).

```
Modelo (estructura)   →   Metodología (detalle de ejecución)
   "¿en qué orden?"            "¿cómo exactamente?"
```
