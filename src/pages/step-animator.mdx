# StepAnimator — Guía de uso

`StepAnimator` es un componente React reutilizable que divide cualquier explicación por pasos en dos zonas:

- **Canvas superior** — el área visual que tú controlas por completo.
- **Panel inferior** — título del paso, bloque de código opcional, descripción y controles de navegación.

---

## Importación

```tsx
import { StepAnimator, type StepData } from '@site/src/components/GitBranchAnimation';
```

---

## Interfaz

### `StepData` — estructura de cada paso

```ts
interface StepData {
  title: string;   // Título que aparece en el panel inferior
  code?: string;   // Bloque de código (opcional). Se omite si no se incluye
  desc: string;    // Descripción del paso
}
```

### `StepAnimatorProps` — props del componente

| Prop | Tipo | Obligatorio | Por defecto | Descripción |
|---|---|---|---|---|
| `steps` | `StepData[]` | ✅ | — | Array con los datos de cada paso |
| `renderCanvas` | `(step: number) => ReactNode` | ✅ | — | Renderiza el canvas según el paso **1-based** |
| `renderBadge` | `(step: number) => ReactNode` | — | `undefined` | Badge extra entre el contador y el título |
| `accentColor` | `string` | — | `#3b82f6` | Color del badge contador y los puntos de navegación |

---

## Uso básico

Solo son obligatorios `steps` y `renderCanvas`. El ejemplo mínimo muestra el número del paso como contenido del canvas:

```tsx
import { StepAnimator, type StepData } from '@site/src/components/GitBranchAnimation';

const pasos: StepData[] = [
  {
    title: 'Paso 1: Inicializar',
    code:  'git init',
    desc:  'Crea la carpeta .git y convierte el directorio en un repositorio.',
  },
  {
    title: 'Paso 2: Añadir archivos',
    code:  'git add .',
    desc:  'Mueve todos los archivos al área de staging.',
  },
  {
    title: 'Paso 3: Primer commit',
    code:  'git commit -m "primer commit"',
    desc:  'Guarda los cambios en el historial del repositorio.',
  },
];

export default function Demo() {
  return (
    <StepAnimator
      steps={pasos}
      renderCanvas={(step) => (
        <div style={{
          background: '#0f172a', height: 180,
          display: 'flex', alignItems: 'center', justifyContent: 'center',
        }}>
          <span style={{ color: '#60a5fa', fontSize: 96, fontWeight: 'bold' }}>
            {step}
          </span>
        </div>
      )}
    />
  );
}
```

---

## `renderBadge`: badge de estado

`renderBadge(step)` devuelve un nodo React que se inserta **entre el contador y el título** del paso. Es útil para mostrar la rama activa, el estado del sistema o cualquier indicador contextual.

```tsx
<StepAnimator
  steps={pasos}
  renderCanvas={(step) => <MiCanvas step={step} />}
  renderBadge={(step) => {
    const estados = ['Limpio', 'Staged', 'Committed'];
    const colores = ['#94a3b8', '#f59e0b', '#22c55e'];
    const col = colores[step - 1];
    return (
      <span style={{
        background: col + '22',
        color: col,
        border: `1px solid ${col}66`,
        borderRadius: 12,
        padding: '2px 10px',
        fontSize: 12,
        fontWeight: 'bold',
        fontFamily: 'monospace',
      }}>
        {estados[step - 1]}
      </span>
    );
  }}
/>
```

---

## `accentColor`: personalizar el color

El color de acento se aplica al **badge del contador** (`1 / 3`) y al **punto activo** de los dots de navegación.

```tsx
{/* Verde — para temas de pruebas */}
<StepAnimator steps={pasos} renderCanvas={...} accentColor="#22c55e" />

{/* Violeta — para patrones de diseño */}
<StepAnimator steps={pasos} renderCanvas={...} accentColor="#8b5cf6" />

{/* Naranja — para flujos de trabajo */}
<StepAnimator steps={pasos} renderCanvas={...} accentColor="#f97316" />
```

## Ejemplo en vivo: ciclo de vida de un cambio en Git

El siguiente ejemplo muestra cómo construir un canvas simple con tres zonas que se activan progresivamente:

export const demoPasos = [
  {
    title: 'Paso 1: Working Directory',
    code:  'git status',
    desc:  'El archivo existe solo en el directorio de trabajo. Aún no está rastreado por Git.',
  },
  {
    title: 'Paso 2: Staging Area',
    code:  'git add index.java',
    desc:  'El archivo pasa al área de staging. Git lo marcará en el próximo commit.',
  },
  {
    title: 'Paso 3: Repository',
    code:  'git commit -m "Añade index.java"',
    desc:  'El archivo queda guardado en el historial. El cambio ya es permanente.',
  },
];

export function ZonasCanvas({ step }) {
  const zonas = [
    { label: 'Working\nDirectory', color: '#94a3b8', desde: 1 },
    { label: 'Staging\nArea',      color: '#f59e0b', desde: 2 },
    { label: 'Repository',         color: '#22c55e', desde: 3 },
  ];
  return (
    <div style={{
      background: '#0f172a',
      padding: '32px',
      display: 'flex',
      gap: 20,
      justifyContent: 'center',
      alignItems: 'center',
    }}>
      {zonas.map((z, i) => (
        <React.Fragment key={z.label}>
          <div style={{
            opacity: step >= z.desde ? 1 : 0.2,
            transition: 'opacity 0.4s ease',
            textAlign: 'center',
          }}>
            <div style={{
              width: 110,
              height: 70,
              borderRadius: 8,
              border: `2px solid ${z.color}`,
              display: 'flex',
              alignItems: 'center',
              justifyContent: 'center',
              boxShadow: step >= z.desde ? `0 0 12px ${z.color}44` : 'none',
              transition: 'box-shadow 0.4s ease',
            }}>
              <span style={{
                color: z.color,
                fontSize: 11,
                fontFamily: 'monospace',
                whiteSpace: 'pre',
                textAlign: 'center',
              }}>
                {z.label}
              </span>
            </div>
          </div>
          {i < 2 && (
            <span style={{ color: '#334155', fontSize: 24, userSelect: 'none' }}>→</span>
          )}
        </React.Fragment>
      ))}
    </div>
  );
}

<StepAnimator
  steps={demoPasos}
  accentColor="#22c55e"
  renderCanvas={(step) => <ZonasCanvas step={step} />}
  renderBadge={(step) => {
    const labels = ['Working Dir', 'Staging Area', 'Repository'];
    const cols   = ['#94a3b8',    '#f59e0b',      '#22c55e'];
    const col = cols[step - 1];
    return (
      <span style={{
        background: col + '22',
        color: col,
        border: `1px solid ${col}66`,
        borderRadius: 12,
        padding: '2px 10px',
        fontSize: 12,
        fontWeight: 'bold',
        fontFamily: 'monospace',
      }}>
        {labels[step - 1]}
      </span>
    );
  }}
/>

## Tips

:::tip
**El paso siempre es 1-based**

`renderCanvas` y `renderBadge` reciben el paso empezando en **1**, no en 0. Ten en cuenta esto al indexar tus arrays de datos.
:::

:::tip
**Animaciones en el canvas**

Para animar transiciones en el canvas, usa `opacity` o `transform` con CSS `transition` sobre los elementos internos, comparando el `step` recibido con el valor de aparición de cada elemento.

```tsx
renderCanvas={(step) => (
  <div style={{ opacity: step >= 2 ? 1 : 0, transition: 'opacity 0.4s' }}>
    Aparece en el paso 2
  </div>
)}
```
:::

:::tip
**Sin estado externo**

`StepAnimator` gestiona su propio estado interno. No necesitas `useState` fuera del componente; simplemente pásale los datos y las funciones de render.
:::

:::tip
**`code` es opcional**

Si un paso no tiene comando asociado, omite la propiedad `code` y el bloque de código no se renderizará:

```ts
{ title: 'Concepto teórico', desc: 'Explicación sin comando git.' }
```
:::
